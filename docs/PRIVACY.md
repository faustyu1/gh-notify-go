# Политика конфиденциальности

Черновик для публикации: GitHub требует ссылку на политику конфиденциальности
у публичного App, Telegram — у бота с платежами или запросом данных. Перед
публикацией подставь настоящее контактное лицо, юрисдикцию и адрес хостинга.

## Какие данные хранятся

**О пользователе Telegram**: числовой `telegram_id`, код языка клиента,
выбранный язык интерфейса. Имя, username, номер телефона и аватар не
сохраняются.

**О чате**: числовой `telegram_chat_id`, название, тип, id топика форума,
окно «без звука», и кто добавил бота в чат.

**Об установке GitHub App**: id установки, логин и тип аккаунта, срок жизни
токена и сам токен установки в зашифрованном виде (AES-GCM, ключ — в
переменной окружения, не в базе).

**О подключённых репозиториях**: id и полное имя репозитория, настройки
событий и фильтров, время последнего события.

**Журнал действий**: кто и когда подключил репозиторий, удалил интеграцию,
поменял фильтры или заглушил чат.

**Очередь доставки**: отрендеренный текст уведомления живёт в очереди до
отправки. Содержимое событий (тексты коммитов, заголовки и тела issue)
проходит через сервис, чтобы попасть в сообщение.

## Чего нет

Бот не читает сообщения в групповых чатах: он реагирует только на своё
добавление и удаление. Никакой аналитики, рекламы, профилирования и передачи
данных третьим лицам, кроме двух обязательных получателей — Telegram (доставка
сообщений) и GitHub (получение событий).

## Сколько хранится

Данные живут, пока живёт интеграция. Удаление App с аккаунта GitHub удаляет
установку и все её интеграции. Удаление бота из чата останавливает доставку.
Одноразовые токены привязки установки живут час.

## Как удалить свои данные

Отключить репозитории кнопкой «Отключить» на экране интеграции, удалить App в
настройках GitHub (`Settings → Applications → Installed GitHub Apps`) и
удалить бота из чатов. Для полного удаления записей о пользователе — напиши
на контактный адрес ниже.

## Безопасность

Вебхуки GitHub проверяются по HMAC-SHA256. Токены установок шифруются в базе.
Подключать репозитории и менять настройки чата может только администратор
этого чата — права проверяются у Telegram в момент действия.
